# Unipass
A system made to aid university event management by providing convenient payment processing, event posting, and verification of attending students using a dynamic QR system. 

## This is an academic project from the Multimedia University curriculum and is not a product. This project is meant to test student's knowledge in software design.

---

## Running the Project

To quickly start the development servers, double-click the **`run.bat`** file in the root folder of this project.

The launcher will:
1. Automatically detect and list your local IPv4 address(es) (useful if you are testing on a physical phone via Wi-Fi and need to configure `COMP_IP` in `mobile/src/config.ts`).
2. Ask you to select your preferred startup configuration (e.g. Backend + Android, Backend only, or Android only).
3. Open individual Command Prompt windows for the backend and frontend servers so you can view all logs side-by-side.
